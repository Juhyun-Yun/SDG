🔗 우리 학급에 연결하기

다른 선생님도 이 앱을 자기 학급용으로 쓸 수 있어요. 아래 가이드를 따라 우리 학급 시트와 연결해주세요.

📚 처음 사용하는 선생님이라면 (3단계 가이드)
  1. ① 스프레드시트 사본 만들기 제공받은 SDG 리틀 히어로 템플릿 시트를 열고 파일 → 사본 만들기를 누르세요. 사본 이름은 "우리반 SDG 히어로" 처럼 자유롭게 지정합니다. (Apps Script 코드도 자동으로 함께 복사됩니다.)
  2. ② Apps Script 새 배포 내 사본 시트에서 확장 프로그램 → Apps Script를 열고, 우상단 배포 → 새 배포 클릭. 유형은 웹 앱, ⚠️ 액세스 권한은 반드시 모든 사용자(Anyone) 로 설정해야 합니다 (Google 계정 보유자/본인만으로 두면 데이터를 못 받아옵니다). 설정 후 배포를 누르고 표시된 웹 앱 URL을 복사합니다.
  3. ③ 아래 두 칸에 URL 붙여넣기 "본부 URL"엔 위에서 받은 웹 앱 URL을, "스프레드시트 주소"엔 사본 시트의 브라우저 주소창 URL을 각각 붙여넣고 저장. 저장 후 페이지를 새로고침(F5)하면 우리 학급 데이터가 표시됩니다.

현재 사용 중:

아래 '시트 열기' 버튼이 여는 주소입니다.

🔗 학생용 접속 주소

이 주소를 학생들에게 공유하면, 학생이 링크로 들어올 때 우리 학급 데이터에 자동으로 연결되며, 학생 화면에는 선생님 메뉴가 보이지 않게 됩니다.
