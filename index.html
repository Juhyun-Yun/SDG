✅ 이 시트에 직접 연결됨

이 앱은 선생님 구글 시트에서 직접 실행 중입니다. 모든 기록은 이 시트에만 저장돼요. 아래 학생용 주소를 공유하세요.

🔗 우리 학급 시트에 연결하기

지금은 정적 호스팅(예: 깃허브)에서 실행 중이에요. 우리 학급 데이터를 쓰려면 아래에 앱스스크립트 웹 앱 URL을 붙여넣어 주세요.

📚 처음 사용하는 선생님이라면 (3단계 가이드)
  1. ① 스프레드시트 사본 만들기 제공받은 SDG 리틀 히어로 템플릿 시트를 열고 파일 → 사본 만들기. (Apps Script 코드도 함께 복사됩니다.)
  2. ② Apps Script 새 배포 내 사본 시트에서 확장 프로그램 → Apps Script → 우상단 배포 → 새 배포. 유형 웹 앱, ⚠️ 액세스 권한 모든 사용자(Anyone). 배포 후 표시된 웹 앱 URL 복사.
  3. ③ 아래 칸에 URL 붙여넣기 복사한 웹 앱 URL(끝이 /exec)을 붙여넣고 저장하면 우리 학급 데이터가 연결됩니다.

🔗 학생용 접속 주소
